## 中文

`v0.3.0` 在 v0.2.0 的类型化 DOM 与核心 React 19 基线上，集中交付异步资源、
生命周期、流式 SSR、React DOM operational APIs 和全量公共 API 文档门禁。

### 主要变化

- 新增 React 19.2 `Activity` visible/hidden 绑定，支持隐藏期间保留 state、清理
  Effect，并在恢复可见时重新建立 Effect。
- 新增 identity-stable Promise resources、React 19 `use` 和局部 Error Boundary，
  覆盖 fulfilled、pending、rejected 与 reset-key retry。
- 新增 Web Streams 流式 SSR、Suspense shell/delayed content、abort、all-ready
  静态输出以及真实 hydration。
- 新增 `flushSync` 与 React 19.2 全部 6 个资源提示 APIs，包含类型化 CORS、
  fetch priority、referrer policy、preload destination 与 stylesheet precedence。
- 将公共 API 文档检查从 19 项白名单升级为全库自动发现；228/228 个显式公共
  声明均带 doc comments，并有缺失声明、泛型、extern 与前缀碰撞回归。
- 加强 GitHub Release 发布链路：Release 触发 Actions，验证 tag/main 身份、
  严格 package 清单、SHA-256、mooncakes.io 精确版本和独立下游 runtime。

### 可验证指标

- MoonBit tests：58/58。
- Chromium conformance：12/12，非预期 React/page diagnostics 为 0。
- Node streaming SSR：3/3，progressive chunks 2、allReady 1、abort callback 1。
- React DOM resource hints：6/6；重复调用后精确 DOM nodes 6、外部请求 0。
- 公共声明文档：228/228（100%）；缺失 0。
- 发布压缩包：严格 18 文件，unexpected files 0；实际字节数与 SHA-256 由同一
  Release 的 `SHA256SUMS` 提供。
- 发布后独立模块必须精确解析 `tiye/react@0.3.0`，通过 check/build、Node SSR
  runtime、Chromium render/hydration 和零 diagnostics 验证。

完整变更见 `CHANGELOG.md`。本项目仍处于实验阶段，不建议用于生产环境。

## English

`v0.3.0` builds on the typed DOM and core React 19 baseline from v0.2.0 by
delivering asynchronous resources, lifecycle behavior, streaming SSR, React DOM
operational APIs, and a complete public-API documentation gate.

### Highlights

- Adds the React 19.2 `Activity` visible/hidden binding, preserving state while
  hidden, cleaning up Effects, and restoring Effects when visible again.
- Adds identity-stable Promise resources, React 19 `use`, and local Error
  Boundaries covering fulfilled, pending, rejected, and reset-key retry paths.
- Adds Web Streams SSR, Suspense shell/delayed content, abort control, all-ready
  static output, and real hydration.
- Adds `flushSync` and all six React 19.2 resource-hint APIs with typed CORS,
  fetch priority, referrer policy, preload destination, and stylesheet
  precedence options.
- Replaces the 19-entry public documentation allowlist with automatic discovery
  across the library package. All 228/228 explicit public declarations have doc
  comments, guarded by missing-declaration, generic, extern, and prefix
  regressions.
- Strengthens GitHub Release publication by verifying tag/main identity, the
  strict package manifest, SHA-256, the exact mooncakes.io version, and an
  independent downstream runtime after the Release triggers Actions.

### Verifiable metrics

- MoonBit tests: 58/58.
- Chromium conformance: 12/12 with zero unexpected React/page diagnostics.
- Node streaming SSR: 3/3, with 2 progressive chunks, 1 allReady completion,
  and 1 abort callback.
- React DOM resource hints: 6/6; exactly 6 DOM nodes after duplicate calls and
  zero external requests.
- Public declaration documentation: 228/228 (100%), with zero missing.
- Release archive: strict 18-file manifest with zero unexpected files; exact
  byte size and SHA-256 are attached to the same Release in `SHA256SUMS`.
- After publication, a fresh downstream module must resolve exactly
  `tiye/react@0.3.0` and pass check/build, Node SSR runtime, Chromium
  render/hydration, and zero-diagnostics verification.

See `CHANGELOG.md` for the complete change list. This project remains
experimental and is not recommended for production use.
